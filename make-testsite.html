製作測試站的模擬廣告

「幫我找找看」可以掃描真的網頁。為了展示「找到冒用」的樣子，測試站要放三則用成員照片做的模擬廣告。這頁幫你一次做好三張圖。

1. 選照片

1 到 3 張同一位成員的照片，臉要清楚。照片只在這台電腦上處理。展示時，這位成員要用同一批照片走「幫我找找看」。

2. 下載

    3. 放進測試站並推上 GitHub

    1. 把三張圖放進專案的 testsite/img/ 資料夾，檔名不要改：ad-teacher.jpg、ad-line.jpg、ad-health.jpg。
    2. 推上 GitHub（例如在專案資料夾執行 git add testsite/img && git commit -m "加入測試站模擬廣告" && git push）。
    3. 等一兩分鐘網站更新後，用同一位成員的照片走「幫我找找看」，選「掃描我指定的網頁」並按「內建的測試站」，就會找到這三則。
